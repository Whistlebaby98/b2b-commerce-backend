# 纯领域无副作用算价流水线与可解释算价快照

为了确保后端计价算法与前端 `b2b-portal-web` 的 `calculateCartTotals` 和 `getTierUnitPrice` 严格对齐，并满足对公企业财务审计的严格要求，我们决定：在 `b2b-pricing` 模块中实现纯内存、无副作用的领域算价流水线（协议基价 -> 数量阶梯命中 -> 营销满减/折扣 -> 税费均摊）。算价流水线不仅计算出最终总额，还生成结构化的可解释算价快照（PricingSnapshot），在订单创建时固化存入 `order_line`，避免历史订单因后续价格政策调整而发生数字回算。

## Considered Options

- **纯领域算价流水线 + 算价快照（已采纳）**：与前端无缝对齐，易于编写高覆盖单元测试，对公财务对账完全可解释。
- **数据库存储过程或边查边算**：难以维护、难以测试，容易与前端展示口径产生分钱四舍五入偏差。

## Consequences

- 算价前必须一次性批量载入涉及的全部价格梯度与活动规则，算价过程严禁在循环内发起网络或数据库 I/O。
- `order_line` 必须包含包含算价轨迹的 JSON 快照字段。
